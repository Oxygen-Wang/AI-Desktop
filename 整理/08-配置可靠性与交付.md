# 配置可靠性与交付

## SYS-01 配置存储

**需求：** 配置持久化可靠，可从旧版本升级；损坏配置可恢复，保存失败有提示。

**建议实现：** 延用当前 %LOCALAPPDATA%/QiDesk 下的 JSON，维护格式版本和逐版本迁移。读取后做类型、数值、对象 ID 和交叉引用校验；写入临时文件、完整校验，再替换正式文件并保留备份。变更事务完成后保存一次，避免拖动每个像素都写盘。迁移前备份原文件，迁移失败保留原始输入。

Fences 的注册表模型用于理解字段和兼容导入，不要求栖桌迁回注册表，也不按其字段名重新设计所有设置。

**验收：** 写入中断、磁盘满、文件只读、缺失字段、重复 ID、未知枚举和未来版本输入均不会默默覆盖可用配置。原子保存与快照恢复共用同一提交入口。

当前入口：[Core.cs](../code/src/Core.cs)。参考：[Fences 设置模型](../references/Fences-4.0.0.3-analysis/features/12-settings-model.md)、[SettingsManager.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/SettingsManager.cs>)。上游使用 JSON 不代表其所有写入点都已具备事务保障，本条是栖桌实现要求。

## SYS-02 单实例与启动

**需求：** 多次启动只激活已有应用；登录启动可开关；搜索、展示工作区等命令能转交现有实例。

**建议实现：** 保留当前 Mutex 单实例检查；用当前用户限定的 IPC 通道发送结构化命令，参数只接受明确定义的动作和路径。登录启动使用可撤销的用户级机制，显示实际生效状态。关窗口收托盘与彻底退出在界面中明确。

**验收：** 同时启动两个实例不重复分区；第二次启动可打开已有窗口；IPC 不接受任意命令执行；关闭登录启动后下一次登录不再启动；卸载移除本程序创建的启动项。

当前入口：[Program.cs](../code/src/Program.cs)、[McpBridge.cs](../code/src/McpBridge.cs)、[ManagerWindow.cs](../code/src/ManagerWindow.cs)。上游：[SingleInstanceChecker.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/SingleInstanceChecker.cs>)、[RegistryHelper.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/RegistryHelper.cs>)。Fences 命令行参数只整理为“命令分发能力”，无需复制其内部参数名称。

## SYS-03 诊断与故障报告

**需求：** 用户能提供足够信息定位桌面挂接失败、配置错误和文件操作异常，并控制是否导出。

**建议实现：** 本地滚动日志包含版本、功能阶段、错误码、宿主窗口类、显示拓扑和操作事务 ID；常见路径可脱敏。日志设置大小与保留上限，敏感配置和 AI 密钥不写入。诊断导出先展示文件清单，默认只保存到本地。崩溃恢复只做最小可靠操作，避免在未处理异常回调里大量读取系统状态。

**验收：** 无权限写日志不导致主程序失败；磁盘占用有上限；导出包不含 token.txt、transfer-token.txt、API 密钥或不相关文件；日志可以区分“宿主未找到”“绑定失效”“文件操作取消”。

参考：[LogManager.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/LogManager.cs>)、[Fences 崩溃报告资料](../references/Fences-4.0.0.3-analysis/features/21-crash-reporting.md)。BugSplat/MixPanel 等厂商组件不作为依赖移入栖桌，自动上传也不是本需求的默认行为。

## SYS-04 安装更新与卸载

**需求：** 安装后普通重启仍可运行，升级保留配置，卸载后桌面图标和右键恢复正常。

**建议实现：** 先维护可直接运行的正式产物和配套版本清单，再决定是否增加安装器。安装路径与用户数据路径分离；更新新版本前校验来源和哈希，保留可回退版本。菜单注册、启动项、快捷键和桌面可见性都通过同一退出/卸载清理流程恢复，清理只处理本程序拥有的对象。

自更新为后续能力，可先提供版本提示及用户手动安装。不要复用 Fences 的授权、更新服务或二进制锁定组件。

**验收：** 安装、登录启动、重启、升级、回退、卸载依次验证；升级不覆盖用户配置；旧实例退出后才切换版本；卸载不删除用户桌面文件。Windows Sandbox 的一次性状态不用于证明安装在真实系统重启后持久有效。

当前入口：[build.ps1](../code/build.ps1)、[start.ps1](../code/start.ps1)、[DesktopShellActions.cs](../code/src/DesktopShellActions.cs)、[Controller.cs](../code/src/Controller.cs)。参考：[DesktopFramesPlus 升级说明](code/DesktopFramesPlus-main/HowToUpgradeToDesktopFramesPlus.md)、[Fences 更新资料](../references/Fences-4.0.0.3-analysis/features/18-update.md)。
