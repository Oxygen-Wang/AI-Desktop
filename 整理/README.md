## 如何使用

每个需求有唯一 ID。功能总表列出全部 ID，专题文档写用户需求、建议实现、验收条件和来源。Fences 3/4、重复反编译目录和 DesktopFramesPlus 中的同类功能合并描述，差异写在同一条内。

状态“已有代码”只表示本次找到对应源码入口，不代表通过真实桌面验收；“部分”表示已有基础但缺少完整语义或验证；“候选”表示本次未找到完整实现，不等同于断言整个工程绝对没有。

P0 是桌面核心可靠性；P1 是核心使用体验；P2 是可选增强。优先级是基于栖桌当前代码的建议，不是参考项目的原始优先级。

## 证据边界

- DesktopFramesPlus 可读源码是实现参考；其 README 和手册说明产品行为，不能替代代码及实测。

- 本次不把破解、激活绕过、Steam 验证、遥测营销、二进制自锁或私有资源包解密列入产品需求。保留本地配置恢复、诊断等有直接用户价值的能力。
