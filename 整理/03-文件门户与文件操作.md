# 文件门户与文件操作

## FILE-01 文件夹门户

**需求：** 在分区直接查看真实目录，进入子目录、后退、上一级；明确“打开系统文件夹”与“组内导航”两个动作。

**建议实现：** 数据源返回文件项，分区窗口只负责显示。导航状态包含根目录、当前位置、前进后退栈、选中项和滚动位置；切换根目录时释放旧监听并清空历史。目录不可访问时显示原因与重试，不把空列表当作目录真的为空。

**验收：** 子目录导航、目录删除、无权限、网络盘断开及恢复时无崩溃；返回后保留选择和滚动位置。

当前入口：[PortalSession.cs](../code/src/PortalSession.cs)、[FenceWindow.cs](../code/src/FenceWindow.cs)。上游：[PortalFrameManager.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/PortalFrameManager.cs>)。Fences 来源：[文件夹视图分析](../references/Fences-4.0.0.3-analysis/features/07-folder-views.md)。变化更新见 RULE-03，不在这里重复实现监听机制。

## FILE-02 过滤排序与视图

**需求：** 目录内按名称或通配符筛选，按名称、类型、大小、时间排序，支持图标、列表和详情；清楚显示当前存在过滤。

**建议实现：** 把数据枚举、全局忽略、局部忽略、临时过滤、排序和渲染分开。临时过滤不得修改归属或删除文件。多模式过滤采用包含集合与排除集合，明确空集合语义；沿用栖桌既有忽略语法，避免直接引入上游“>”排除语法造成两套规则。保存每分区的排序、方向、视图和图标尺寸。

**验收：** 过滤结果为零时可一键清除；切换视图不丢选中；排序同值时结果稳定；大目录输入过滤不卡 UI。

当前入口：[FileFeatures.cs](../code/src/FileFeatures.cs)、[IgnoreFiles.cs](../code/src/IgnoreFiles.cs)、[Core.cs](../code/src/Core.cs)。上游行为参考：[Portal Fence Filters](code/DesktopFramesPlus-main/TIPS.md)。高级规则分类见 RULE-01/02，不能把过滤与分类混成一个动作。

## FILE-03 文件操作与系统菜单

**需求：** 正常使用复制、移动、粘贴、重命名、删除、属性和第三方右键扩展；拖到目录与拖到普通分区具有明确不同的结果。

**建议实现：** 继续使用现有 IFileOperation 和 Shell 菜单桥接，文件路径不拼成命令行交给终端。由统一操作层决定复制或移动、冲突和取消；操作成功后刷新相关视图。多选操作保留逐项结果，部分失败不能报告全部成功。菜单会话负责释放 COM、PIDL 和菜单句柄，并转发 IContextMenu2/3 消息。

**验收：** 同名冲突、取消、只读目录、文件占用、跨盘移动、回收站删除、中文长文件名及第三方子菜单实测通过；普通分区的移出不删除实体文件。

当前入口：[NativeFileOperations.cs](../code/src/NativeFileOperations.cs)、[NativeMenus.cs](../code/src/NativeMenus.cs)、[ShellActions.cs](../code/src/ShellActions.cs)、[DragTransfer.cs](../code/src/DragTransfer.cs)。上游：[CopyPasteManager.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/CopyPasteManager.cs>)。Fences 菜单证据只用于解释 Shell 集成，不要求栖桌采用相同的 Explorer 内部扩展结构。

## FILE-04 文件与启动目标身份

**需求：** 正确展示和打开文件、目录、LNK、URL，以及用户添加的应用 URI；区分快捷方式文件本身与它指向的目标。

**建议实现：** 使用统一 ItemIdentity 和 LaunchTarget：原始项目路径、解析目标、参数、工作目录、启动类型、显示名。LNK 通过 Shell COM 解析，保留参数和工作目录；解析失败仍可让 Shell 打开原始快捷方式。URI 不按普通磁盘路径做 File.Exists。Store 应用、Steam/Spotify 等协议列为独立用例，不能把文档中“支持”当作本项目已支持。

**验收：** 含空格参数、相对目标、断开的网络路径、URL、带参数 LNK、应用协议分别测试；定位文件与启动目标的菜单文案明确。

当前入口：[Shell.cs](../code/src/Shell.cs)、[ShellActions.cs](../code/src/ShellActions.cs)。参考：[Fences 图标身份](../references/Fences-4.0.0.3-analysis/features/03-icons.md)、[TargetChecker.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/TargetChecker.cs>)、[IconManager.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/IconManager.cs>)。启动项编辑见 EXT-01。

## FILE-05 图标缩略图与加载队列

**需求：** 图片显示内容缩略图，其他文件使用系统图标；大目录和快速滚动不阻塞界面。

**建议实现：** 延用栖桌 WIC/Shell 缩略图实现。缓存键含规范化路径、修改时间、大小和目标尺寸；队列设并发与容量上限，优先可见项，视图切换时取消旧请求；将解码结果回到 UI 时核对项目仍对应本次请求。失败回退图标，不能反复无限重试。

**验收：** 透明图、损坏图、超大图、快速切目录、文件内容修改、文件删除后更新均正常；预览不长期锁文件；重复滚动后内存和句柄不持续上涨。

当前入口：[Thumbnails.cs](../code/src/Thumbnails.cs)。上游：[LazyIconLoader.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/LazyIconLoader.cs>) 的请求队列与取消机制可作对照。

## FILE-06 失效项检查

**需求：** 发现失效快捷方式或已移动文件，可重新定位、移除引用或重试；离线磁盘和网络不可用应与永久丢失区分。

**建议实现：** 状态分为可用、检查中、暂不可访问、缺失、格式无法解析。后台按批检查并限频；重定向目标由用户选择后更新身份与缓存。批量清理只移除配置引用，提供预览和撤销。

**验收：** 拔出移动硬盘不会自动清空分区；重连后恢复；批量清理不删除实体文件。

上游：[TargetChecker.cs](<code/DesktopFramesPlus-main/Code/Desktop Frames/TargetChecker.cs>)、[手册失效快捷方式说明](code/DesktopFramesPlus-main/desktop_frames_simple_manual.md)。栖桌可把此能力接入 FILE-04 的身份模型，不再创建单独的一套路径表。
