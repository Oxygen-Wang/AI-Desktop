# 组件功能区与首次使用教程

组件功能区是桌面的可拖动入口条。在桌面模式中显示，跟随全局隐藏；左键“＋ 添加组件”打开组件库，可单个添加或勾选组合。侧栏“插件与组件”、主页按钮和托盘也提供入口。

桌面空白处左键长按约 0.35 秒，再拖动框选，松开后提供：桌面分组、文件夹映射、在此添加组件、取消。选择组件会从框选位置排列；区域不足时继续排到后续页面。普通添加寻找空位，避免与已有分组、组件重叠。可以拖动标题、缩放、改变透明度并选择页面。组件标题栏只保留颜色圆点与名称，不再显示右上角“···”按钮；设置、锁定、透明背景与移除通过右键菜单进入，双击标题仍可重命名。

待办清单支持在面板内直接编辑：点击任务文字即可修改，回车或失焦保存；勾选表示完成；点每行右侧 ✕ 删除并自动修正已完成索引；在底部输入框输入后回车或点 ＋ 添加新事项。✕ 图标默认隐藏、鼠标悬停到该行才显示。勾选完成的任务折叠进“已完成 N 条”区域并记录完成时间（显示为 HH:mm 或“今天 / 昨天 HH:mm”），点击该栏展开或收起，取消勾选移回待办；完成时间保存在组件的 TaskTimes 中，删除任务时同步重排索引。编辑期间组件临时允许键盘激活，结束后恢复为不抢焦点的桌面挂接状态，因此无需再打开设置窗口。

首批七种类型：时钟（时区/秒数）、月历、便签、目标日期倒计时、可勾选待办、可开始/暂停/重置的番茄钟、按自定义多行选项抽签的随机选择器。在此基础上新增五种渲染类型：计算器、习惯打卡、系统状态、照片轮播与网易云音乐，合计十三种。世界时钟可以用多个时钟实例组合；“今天吃什么”“骰子”“灵感抽签”可以通过随机选择器制作插件。

工作区快捷键由 Shift＋Z 改为用户选择的 Alt＋Space。保留冲突检测和托盘入口。首次运行本版自动展示五步教程：添加入口、左键长按框选、菜单选项、组合安装分享、搜索快捷键。关闭或完成后记录 TutorialVersion=1，不再次自动弹出；侧栏和组件库可以重播。新用户不再被自动放置时钟/日历，已有组件保留。

## 安装与分享

- 单个插件：`.qidesk-plugin.json`，沿用原格式并增加 tasks、focus、choice 类型。新增内置实例 ID 为 qidesk.tasks、qidesk.focus、qidesk.choice，避免占用此前允许用户自定义的 focus 等 ID。
- 组合包：`.qidesk-pack.json`，format=qidesk.component-pack，version=1。包含插件清单和组件模板。
- 制作：组件库“制作自己的插件”，输入名称、类型、内容/选项与颜色。
- 组合：勾选库中组件后“保存勾选项为组合”，或选择已有桌面组件导出。组合库可反复添加、导出和移除。
- 安装：选择文件、查看安装预览、安装到库，再决定是否添加到桌面。相同包重复安装不重复添加；同 ID 不同插件配置明确拒绝。

组合导出保留所选组件内容、外观、相对位置、时区、目标日期和专注时长，不包含文件归属、工作区路径、正在运行的计时器或任务勾选状态。导入与组合添加先在独立状态副本中验证，失败不产生部分安装。保留既有撤销机制。

本版插件采用 JSON 描述内容、样式和十三种渲染类型：clock/calendar/weather/note/countdown/tasks/focus/choice，以及新增的 calc（计算器）、habit（习惯打卡）、system（系统状态）、photos（照片轮播）、music（网易云音乐）。不是外部 DLL/JavaScript 执行接口。计算器使用本地表达式解析器，系统状态通过系统 API 读取，照片轮播读取本地图片，网易云音乐读取其窗口标题并用系统媒体键控制；音乐控制、在线日程等仍需要相应数据服务，可作为后续新的渲染器。

示例：plugins/examples/what-to-eat.qidesk-plugin.json、creative-prompt.qidesk-plugin.json、focus-desktop.qidesk-pack.json、daily-water.qidesk-plugin.json、utility-desk.qidesk-pack.json。

## 时钟与日历（农历）

日历组件按当代中文日历重做：每个日期格子显示公历日与农历小字，初一显示月份，节气由本地公式计算，公历节日（元旦、国庆等）与农历节日（春节、元宵、端午、七夕、中秋、重阳、腊八、除夕）优先于农历日显示。周末日期用强调色区分，今天整格高亮并显示农历。日历可勾选“在日历中显示时钟”，在标题下方显示当前时间与“10 月 16 日 星期五 · 农历九月初七”；时钟组件本身也在日期行追加农历日。农历数据覆盖 1900–2100，超出范围自动回退公历。

日历设置新增“显示农历、节气与节日”“在日历中显示时钟”“一周从周一开始”，并沿用“显示秒数”。默认日期从周一开始，可切换为周日；默认显示农历与内置时钟。新建日历默认 330×400，缩小时内容可滚动而不裁切。MCP 的 qidesk_update_widget 同步支持 ShowLunar、ShowCalendarClock、WeekStartMonday。

## 网易云音乐

新增 `music` 渲染类型与内置组件“网易云音乐”（id=qidesk.music，强调色 #C20C0C）。网易云桌面客户端没有公开的本地播放接口，这里通过 `Process.GetProcessesByName("cloudmusic").MainWindowTitle` 读取正在播放信息：窗口标题播放时形如“歌名 - 歌手”，按第一个 ` - ` 拆分歌名与歌手，空闲窗口标题为“网易云音乐”时视为未播放。控制按钮“上一首 / 播放 / 暂停 / 下一首”用 `keybd_event` 发送系统媒体键（VK_MEDIA_PREV_TRACK 0xB1、VK_MEDIA_PLAY_PAUSE 0xB3、VK_MEDIA_NEXT_TRACK 0xB0，扩展键标志），作用于当前媒体会话。每 2 秒轮询一次标题，仅在变化时刷新界面。不显示专辑封面与进度，也不读取账号信息。环境变量 `QIDESK_MUSIC_PROCESS` 可指向其它进程名以便复用或本地验证（验证时用记事本窗口确认标题解析端到端可用）。
