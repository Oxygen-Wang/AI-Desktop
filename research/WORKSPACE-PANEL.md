# 工作区面板与桌面小猫

参考 `references/PathCat-main`（径猫）的文件侧栏，把它做成栖桌风格的**面板**，并加一只**桌面小猫**作为开合入口。面板有两种状态：**浮动**（Alt＋Space / 小猫召唤，置顶独立窗口）和**钉在桌面**（变回一个普通分区），两者可以互相切换。

## 为什么是浮动面板

PathCat 是一只小猫加一条召之即来的侧栏。栖桌原来的 Alt＋Space 是一条搜索浮条，两者位置重叠，因此本轮把 Alt＋Space 让给工作区面板，工作区搜索移到小猫的右键菜单和托盘。

## 面板结构

- 窗口：`WorkspacePanel`（`code/src/WorkspacePanel.cs`），浮动时置顶、不进任务栏、可拖动标题或**空白处**移动，**左右拖动边缘改宽**，位置尺寸记忆在 `State.PanelX/PanelY/PanelWidth/PanelHeight`。
- 顶栏标签：一个面板就是容器，顶栏是若干标签，一次只显示一个。标签有两类（`PanelTab`）：
  - **文件夹标签**：绑定真实目录，能读写的全套文件操作，每个标签独立 `PortalSession` 记录浏览位置。
  - **分区标签**：引用桌面上的一个分区（`GroupId`），只读浏览该分区的项目，不移动磁盘文件。
- 标签操作：点切换、点 × 或中键关闭、点 ＋ 或把文件夹拖到栏位新增、右键可左右移动 / 在资源管理器打开 / 关闭。

## 显示方式与 Ctrl＋滚轮缩放

缩放是一条线，Ctrl＋滚轮（或 `Ctrl＋＋` / `Ctrl＋－`）在线上移动，方向和桌面分区一致：滚轮向上放大、向下缩小。

| 档位 | 说明 |
| --- | --- |
| 图标 96 / 72 / 56 / 44 / 36 / 28 | 与桌面分区同款图标格 |
| 详细信息 | 一行一个，带大小、类型、修改时间 |
| 列表 | 一行一个，紧凑 |
| **可折叠树** | 最紧凑：点 ▸ 展开子目录、▾ 收起，只加载展开过的目录；双击文件打开，方向键左右也能展开 / 收起 |

## 真实文件操作

按 VSCode / Cursor 侧栏的习惯：**直接拖动是移动，按住 Ctrl 拖动是复制**。只在文件夹标签下生效。

- 面板内拖动：落到文件夹图标、另一个标签、空白处或「↑ 上一层」，交给 Windows `IFileOperation`，重名时用系统自己的冲突对话框。
- 拖出到外部程序：拖动时写入 `CF_HDROP`，可以直接拖进 Cursor、浏览器、聊天窗口。
- 剪切 / 复制 / 粘贴：`Ctrl+X` / `Ctrl+C` / `Ctrl+V`；重命名 `F2`；删除 `Delete`，二次确认后进回收站。
- 移动或重命名后调用 `ShellActions.UpdateReferences`，分区归属、忽略路径、工作目录和**面板标签本身**都会跟着改。

## 名称搜索

`Ctrl+F` 展开搜索栏，输入即搜；只在当前文件夹及子目录里**按名称**匹配，不做内容检索，不引入任何向量或语义模型。结果按相对路径显示，双击打开、可拖拽，最多 2000 项，遵循忽略规则并跳过目录链接，后台线程执行并按代次号丢弃过期结果。

## 忽略

- 面板右上角的**忽略图标**是拖放目标：拖文件或文件夹上去就加入全局忽略（生成一条名称规则）。右键可换样式（6 种符号，存在 `State.PanelIgnoreIcon`），或进入忽略规则设置。
- 复用栖桌原有体系：`State.IgnoreRules` 是面板直接写入的地方，不另建一套。
- `.gitignore` / `.cursorignore` 由 `IgnoreFiles.Sync` 自动导入；`IgnoreFiles.Roots` = AI 工作目录 + **面板的文件夹标签**，所以面板内容遵循项目自己的忽略文件；关掉标签后对应规则集会被移除。

## 外观：完全复用桌面分区那一套

面板外观就是一个 `Group`（`State.PanelStyle`），字段与桌面分区完全一致：颜色、色调强度、背景与边框不透明度、方角/圆角、标签颜色字号字体、图标皮肤与颜色。

- **默认方角**，和桌面分区一致。
- 新增三个字段，桌面分区和面板一起生效：`BackgroundStyle`（跟随颜色 / 纯色 / 渐变 / 毛玻璃 / 图片）、`BackgroundImage`、`ImageMode`（填充 / 适应 / 平铺 / 居中）。默认「跟随颜色」的输出与改动前逐字节一致，桌面分区外观不受影响（有测试守着）。
- 「毛玻璃」是半透明渐变加程序生成的细噪点。WPF 分层窗口拿不到系统级模糊，这一档是**拟态**而不是真背景模糊。
- `State.PanelFollowGroupId` 非空时，面板直接使用那个分区的外观，改一处两边一起变。
- 面板内右键「面板外观」可以改边角、底色、背景图片、不透明度、图标皮肤和跟随分区；完整设置在管理面板的「颜色和外观」里。

## 钉到桌面 / 弹成面板

- **钉到桌面**：面板标题上的图钉按钮（或右键菜单）。文件夹标签合成一个 `Kind=文件夹` 的真实分区（顶栏就是这些文件夹），分区标签则合并成宿主分区加成员标签；位置尺寸和外观一并带过去，然后关闭浮动面板。
- **弹成面板**：分区标题右键「弹成工作区面板」。该分区接进面板当标签，桌面那一份先隐藏，面板收起后自动回到桌面（`ManagerWindow.HideDesktopCopies` / `RestoreDesktopCopies`）。
- **Ctrl＋左键多选分区**：在桌面上 Ctrl＋左键点分区标题切换选中态（加粗高亮边框），选中后右键任意一个选中分区选择「弹成工作区面板（N 个分区）」，或直接按 Enter，就把它们一起弹成一个面板。

## 桌面小猫

`DesktopPet`（`code/src/DesktopPet.cs`）。**默认使用 PathCat 自带的状态图**，素材缺失时回退到内置的 WPF 矢量画法。

- 三套形象（`State.PetSkin`）：**默认猫**（`cat/<状态>/`）、**毛绒三花**（`cat/calico/`）、**矢量猫**（代码绘制）。素材来源与授权说明见 `code/assets/cat/SOURCE.md`；将来画好矢量图，覆盖同名文件即可。
- 开合面板：**点击**开合，**鼠标停留约 0.5 秒**自动展开（展开时不抢当前软件的焦点）。
- 拖文件夹到猫身上：新建文件夹标签并展开面板。
- 拖动改位置（记忆在 `State.PetX/PetY`），5 分钟不互动进入睡眠，点一下或再次交互唤醒。
- 大小 75 % / 100 % / 150 % / 200 %。
- **隐藏入口有四个**：小猫右键菜单、托盘「显示 / 隐藏小猫」、全局快捷键 `Ctrl＋Alt＋M`、工作区面板标题上的「猫」按钮。隐藏状态存在 `State.PetVisible`。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Alt＋Space` | 没有选中分区时开合工作区面板；有选中分区时把它们提到最前，再按一次收起（第三次又收回最前）|
| 中键点分区标题 | 同一个动作：没收起就收起，已收起就收回最前 |
| 小猫左键 / 悬停 | 和 `Alt＋Space` 同一个动作：面板开着先收面板；有选中分区时提起 / 收起它们；否则开合 / 展开面板 |
| `Ctrl＋Alt＋M` | 显示 / 隐藏小猫 |
| `Ctrl＋滚轮`、`Ctrl＋＋/－` | 面板缩放五档 |
| `Ctrl＋F` | 面板内按名称搜索 |
| `Ctrl＋C / X / V` | 复制 / 剪切 / 粘贴 |
| `F2` / `Delete` | 重命名 / 移入回收站 |
| `Ctrl＋Shift＋N` | 新建文件夹 |
| `Backspace` | 回到上一层 |
| `Esc` | 先收搜索栏，再收起面板 |
| `Ctrl＋左键`（桌面分区标题） | 多选分区 |
| `Enter`（已选中分区） | 提到最前 / 收起选中分区 |
| `Ctrl＋Alt＋Backspace` | 取消所有工作区选择，分区回到桌面 |

收起只隐藏窗口，`SelectedGroups` 不变，所以第三次按下能原样收回，重建窗口（保存、增删文件）后收起状态也保持。

工作区搜索（原来的 Alt＋Space 浮条）改到小猫右键菜单和托盘里。

## 已知取舍

- 面板不会在失焦时自动收起；用 `Alt＋Space`、`Esc` 或小猫收起。
- 有选中分区时 `Alt＋Space`（或中键点分区）负责把选中分区提到最前 / 收起，收起时只隐藏窗口、不取消选择，也不会显示没有选中的分区；要放回桌面用 `Ctrl＋Alt＋Backspace` 取消选择。
- 标签绑定的文件夹如果暂时不可用，标签会被丢弃，和 PathCat 只保留存在目录的做法一致。
- 「毛玻璃」是拟态，不是系统级背景模糊。
- 钉到桌面时如果标签里既有文件夹又有分区，会分别处理：文件夹进新分区，分区标签恢复成桌面分区（而不是塞进同一个容器）。
- 本次不做 PathCat 的 Skills 技能标签、多选拖拽进度条与撤销栈。
