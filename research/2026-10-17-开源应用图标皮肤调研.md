# 开源应用图标皮肤调研

日期：2026-10-17。状态：调研完成；后续已下载两套选取的图标素材并接入栖桌本地测试版，见 [应用图标皮肤测试](2026-10-17-应用图标皮肤测试.md)。以下候选能力描述与建议保留作为调研记录。

## 场景

让桌面分区里的常见应用图标拥有统一风格，并能整套切换和恢复。截图中程序图标外面的深色圆角底板也影响观感：接入新素材时应提供“无底板”选项，避免新图标继续被旧底板包住。这是根据现有界面提出的设计建议。

## 候选

| 项目 | 能提供什么 | 能否直接在 Windows 整套替换 | 仓库标注许可 |
| --- | --- | --- | --- |
| [Seelen UI](https://github.com/eythaann/Seelen-UI) | Windows 桌面环境的图标包机制；按应用路径、UMID、扩展名匹配，支持明暗图标 | 能在自身界面应用图标包；不能据此认定会改写 Explorer 或栖桌的所有图标 | AGPL-3.0，见仓库 LICENSE |
| [Fluent icon theme](https://github.com/vinceliuice/Fluent-icon-theme) | Fluent 风格的应用、文件夹等图标；文件夹有多种配色 | 原生面向 Linux；在栖桌中需增加 Windows 应用映射与素材加载 | GPL-3.0 |
| [Papirus](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme) | 扁平 SVG 图标主题，提供基础、深色和浅色变体 | 原生面向 Linux；可作为素材候选，不能运行其安装脚本就给 Windows 换肤 | GPL-3.0 |
| [Flat Remix](https://github.com/daniruiz/flat-remix) | 色彩丰富、带少量阴影和渐变的图标主题，多种配色目录 | 原生面向 Linux；需要同样的映射与加载适配 | GPL-3.0 |
| [Shortcut Icon Changer](https://github.com/kemaruya/shortcut-icon-changer) | Windows `.lnk` 图标选择、搜索、恢复默认；支持自选 ICO/PNG | 可更改单个快捷方式，提供命令行应用/恢复；未核实具有按程序自动匹配整套品牌皮肤的功能 | MIT |

Seelen 的格式说明见[官方图标包文档](https://seelen.io/no/blog/seelen-icon-packs)：素材可使用 PNG、JPG、SVG、ICO，映射包含应用路径、UMID 与文件扩展名。项目自身是完整桌面环境；这里建议参考图标包的数据模型，不引入它的整套运行框架。

Shortcut Icon Changer 使用 WPF / .NET Framework 4.8，与本项目技术接近。它的预置素材主要是 Fluent UI Emoji 的 3D / Flat 风格；不能把这些表情图标等同于 Chrome、QQ、MATLAB 等品牌应用的完整皮肤库。

## 建议

优先考虑 **Seelen 的图标包机制 + Fluent 的视觉风格**；Papirus 作为第二套扁平风格候选。以上是接入建议，不代表已经导入素材。

在栖桌设置中提供整套预览、一键应用、恢复原图、未匹配项目列表，以及逐项指定图标。默认只改变栖桌的显示；若以后需要修改真实 `.lnk`，复用已有 `ShortcutIcons`，另保存原图标位置用于恢复。

匹配优先级建议：用户单项覆盖 → 快捷方式目标程序 / UMID → 文件类型 → 原系统图标。配置采用本项目已有 JSON，无需为模仿参考项目引入 YAML 或新的运行时。

素材包与应用映射分开维护。图片中的 Everything、QQ、Bandizip、ImageGlass、MATLAB、360、安全工具及小众国产软件，需要逐项核对实际覆盖；本轮没有确认所有这些程序都在上述主题中。缺失时保留原图，并允许补充。

图标包应随附来源与许可证。这里记录的是仓库标注，不将“公开可下载”直接当作可随意再分发的授权。

## 原始调研范围与后续

原始调研只进行了开源项目查找、官方文档核对和方案整理。后续按用户“整下来 test”的要求下载了固定版本素材与相关参考源码，制作了 Fluent / Papirus 本地测试皮肤，具体范围与结果见 [应用图标皮肤测试](2026-10-17-应用图标皮肤测试.md)。没有安装第三方桌面环境或执行其安装脚本，也没有改写系统图标或真实快捷方式。
