# 栖桌 0.6：桌面核心与文件搜索

本次收尾以桌面整理为主。Ditto / 剪贴板扩展按用户要求暂停，相关草稿已移到 `experimental`，不参与构建、不注册监听或快捷键。新的生活组件暂缓；已完成的时钟、日历、文字卡片、日期倒计时仍可在插件页面添加和移除。

## 桌面与文件操作

- 更新旧配置时启用原图标层隐藏、子文件夹内导航，并提高原来过低的分区颜色强度。用户随后手动修改这些选项会正常保存，不会在每次验证或启动时强制覆盖。
- 分区属于 Explorer 桌面宿主，原图标层使用恢复租约；停止桌面模式或退出时恢复之前的可见状态，异常退出由独立恢复进程处理。隐藏的是原图标层，包括系统图标。
- 文件夹映射中的文件夹双击进入当前视图；工具栏返回、上一级，以及 Alt+左 / Alt+上用于导航。普通分组内的文件夹双击打开同一分组的详情浏览窗口。标题或边框双击依旧打开对应系统文件夹。
- 真实文件夹目标接受文件拖放，默认复制，Shift 移动；拒绝放到文件、复制目录到自身或子目录。普通分组空白处仍是分组归属操作。复制/移动使用 Windows IFileOperation，碰撞与取消由系统处理。
- 标题栏 ⇅ 与原生右键菜单可按名称、类型、修改时间、大小及升降序排序。Ctrl+滚轮保留图标、列表、详情切换。
- 外观页提供可见色块、透明选项及实时样例。布局快照显示分区位置、图标和保存时间，点击缩略图可放大，再选择恢复。
- PNG/JPEG 等实际图片缩略图继续由 WIC / Windows 缩略图接口提供；大图和详情窗口保留实际图片预览。

## 文件入口

- 文件搜索复用正在运行的 Everything 1.4 索引。查询工具是官方 ES 1.1.0.38 x64，通过本机 IPC 调用 Everything；无需模拟点击窗口。可进入用户指定的 Everything 界面。
- 搜索支持 Everything 表达式；没有可用索引时搜索桌面、分区和已连接项目，最多遍历 5000 项、3 层，跳过目录链接并应用忽略策略。
- 最近打开合并栖桌打开记录与 Windows Recent 快捷方式的目标，最近修改由索引或有界目录扫描提供。它不是对所有应用文件打开事件的全局监控。
- 截图页面按日期预览选定文件夹及系统 Screenshots 目录的图片，保留源文件，不自动采集剪贴板。
- 工作区搜索浮层可切换当前项目或全局范围；项目由 MCP Roots、显式连接或手动选择提供。当前项目是已连接项目，不能推断所有编辑器的前台工作目录。

## AI / MCP

已有 `start-mcp.ps1` 配置入口保持有效，选择最新配套服务。MCP 支持读取和修改全局设置、分区外观与布局、组件设置、排序和规则，并可查询 Everything 元数据。更新有类型、范围与枚举校验，失败时回滚配置；忽略规则仅影响显示。

支持导入 `.gitignore`、`.cursorignore`、`.cursorindexingignore`、`.ignore` 和项目 `.git/info/exclude`，可应用全局或局部分区。连接工作目录后自动关联顶层规则文件；规则的目录、通配符、顺序与 `!` 例外按项目根路径匹配。嵌套规则文件需手动导入，不声称完整模拟 Git 的所有配置来源。

插件为声明式 JSON 卡片配置；不加载任意程序或脚本。图标源在 `assets/qidesk.svg`，构建生成多尺寸 ICO 和嵌入图像。
