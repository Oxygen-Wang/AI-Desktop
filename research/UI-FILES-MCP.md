# 栖桌 0.4.0：新拟物、文件视图、忽略与 MCP

用户要求：透明新拟物界面、类似资源管理器的缩放与详情、隐藏绝对路径、双击系统打开、全局/局部忽略、AI 工作目录检测和 MCP。用户明确选择：规则命中的生成文件自动隐藏，普通分组双击打开系统桌面文件夹。

## 行为

分区背景独立调 alpha，窗口自身保持 Opacity=1，保留彩色边线、标题底衬与文字阴影。背景 0 使用 alpha 1 保留空白命中，视觉透明。管理界面使用浅灰蓝背景、白色高光边线与柔和阴影。

Ctrl＋滚轮按详情、列表、20–96 像素图标递进；右键可直接选择视图。⤢ 展开为同一组的详情窗口，列出名称、大小、类型和修改时间。双击项目使用系统关联打开，标题/边缘/空白打开当前映射目录或系统桌面。没有创建同名目录或复制文件。文件夹映射仍支持可选组内导航。

忽略支持全局/组内、名称通配符和精确项目。精确目录规则包含后代。显示枚举、自动分类和 AI 建议共享规则；删除规则恢复显示，原归属保持。工作目录自动规则只限用户选定根目录，严格分隔边界，默认仅匹配常见生成前缀，临时文件和缓存需另启用。工作目录扫描不读取文件内容，不声称可验证 AI 作者。

## MCP

应用拥有配置并在 UI 线程串行处理变更。命名管道 ACL 仅授权当前 Windows 用户；stdio 服务独立进程不直接写配置。连接可开关，开关关闭后拒绝调用。

工具：qidesk_list_groups、qidesk_list_items、qidesk_list_workspaces、qidesk_list_ignores、qidesk_detect_generated、qidesk_add_ignore、qidesk_remove_ignore、qidesk_register_generated、qidesk_create_portal。

登记生成文件只接受已存在于注册工作目录内的文件/目录，拒绝路径前缀伪装、目录链接及越界。创建分区仅映射已有注册目录。没有暴露任意命令执行、文件写入、移动、删除工具。此限制只作用于本 MCP，不能限制其他 AI 工具自己的文件系统能力。

支持 initialize 协商 2024-11-05、2025-03-26、2025-06-18、2025-11-25 协议；不声称支持后续新协议。结构参考 [官方 MCP schema](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/schema/2025-11-25/schema.ts)。stdio 使用换行 JSON-RPC，标准输出只写协议消息。客户端配置使用稳定启动脚本，选择最新版构建。
