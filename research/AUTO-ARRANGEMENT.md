# 桌面分区自动排列

主页“自动排列分区”、托盘“自动排列当前页分区”，以及“布局和快照”中的“一键排列当前页 / 排列全部页面”提供入口。

“新增分区、尺寸和显示器变化时自动排列”默认关闭。开启后在启动、新增/移除分区、尺寸或页面归属变化、桌面组件/组件区位置变化、显示器工作区变化时重新排布。手动拖动未锁定分区不会立即触发重排；下一次上述变化发生时按自动规则排列。自动模式优先于原有的工作区缩放/显示器档案恢复。

排列只改变分区 X、Y，以及解除已排列分区的边缘锚定；默认保持尺寸、页面、卷起状态、内容和文件归属。开启“排列时按内容缩小分区（只缩不放）”后，未锁定分区按内容收缩多余空白（保留当前每行图标数，空分区收到 220×100），绝不放大；卷起与锁定分区不动。锁定分区及桌面组件保留位置，组件入口条也作为障碍物。

按当前页或各个页面分别规划。从工作区左上方开始留出 16 px 边距，使用已有分组间距和网格设置；优先使用分区原来的显示器，空间不够再使用其他显示器。支持副屏负坐标，候选位置由工作区边缘和障碍物边缘确定。先按原分区顺序尝试，失败时按面积从大到小再试。

所有页面的候选位置先完整验证。放不下时返回提示并保留原配置，不缩小分区、不改变页面，也不提交部分结果。卷起分区按完整展开尺寸预留空间，避免悬停展开后遮挡其他分区。

位置保存至 state.json 和布局档案。一次手动排列对应一个撤销记录；撤销通知用于阻止自动模式立即覆盖恢复的位置。自动触发依据结构和障碍物签名，避免每次文件刷新重新排列。

MCP 新增 qidesk_arrange_groups，可选 scope=current 或 all，返回 arranged、changed、locked 计数。qidesk_update_settings 支持 AutoArrangeGroups 布尔设置。

验证覆盖不同尺寸、锁定/组件/入口避让、负坐标副屏、屏幕溢出、当前页与全部页面、幂等、文件归属保持、持久化、撤销、手动拖动保留、新增重排和实际窗口启动/尺寸调整。预览命令 --render-arrangement 输出 dist/auto-arrange-preview.png。
