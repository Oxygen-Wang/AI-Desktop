0.3.1 同时支持显式“在桌面框选创建”入口和空白处左键长按框选，鼠标消息继续传递给 Explorer。自动快照只清理本软件以 auto- 日期命名的旧自动快照，手动快照保留。显示器布局档案记录分组 ID 与几何信息，不替换文件归属。

## 桌面交互

原图标隐藏为可选开关，默认关闭。它操作真实桌面 ListView 的整层可见状态，因此也包含回收站等系统图标；尚未逐个接管 Explorer 图标。停止、预览和退出会释放显示状态租约。独立恢复进程监视拥有者进程；拥有者异常退出时，仅恢复具有对应租约标识的原窗口，避免窗口句柄重用造成误恢复。

双击监听运行在独立线程。命中查询通过另一个线程执行 IAccessible.accHitTest，避免 Explorer 查询阻塞鼠标钩子。只有真正桌面承载结构及空白区域可以触发；普通文件夹、文件项、拖动和超时点击排除。平台依据：[鼠标钩子线程与超时](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)、[空白与子项命中返回值](https://learn.microsoft.com/en-us/windows/win32/api/oleacc/nf-oleacc-iaccessible-acchittest)、[异步窗口可见状态](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindowasync)。

## 验证与边界

58 项检查通过，包括核心持久化、原生桌面挂接、手势识别、真实测试窗口可见状态与异常退出恢复、文件夹导航、规则组合、布局缩放和档案、快照保留策略。十个设置页面均已通过本软件自身的离屏渲染检查，分组和映射视图另有预览。测试的图标租约使用本软件窗口，没有隐藏用户实际桌面图标。

实际桌面双击、不同 DPI、真实显示器切换、Explorer 重启、与 Fences 同时运行的手势冲突仍需要实测。参考截图没有展示完整规则条件操作，本版仍未覆盖 Fences 全部条件或完整 Shell 右键菜单；真实 AI 模型请求尚未验证。
