# 栖桌 · AI Desktop

第一次打开项目，先看[项目思维导图与目录导航](PROJECT_MAP.md)。主程序使用 C# / WPF；`code` 只放构建 App 所需的文件，`dist` 是本机构建，`output` 是对外分享包。

一个正在开发的 Windows 桌面整理软件。当前交付核心预览版 0.7.1：可以运行，不代表已经完成 Fences 3 功能等价。

本轮修复与范围见 [桌面核心与文件搜索](research/CORE-0.6.md)。Ditto / 剪贴板扩展暂缓，不参与当前构建。

## 启动

在 PowerShell 中执行启动脚本，它会选择 `dist\latest.txt` 指定的最新构建：

```powershell
& D:\fences\code\start.ps1
```

需要直接启动桌面模式时，可以给最新 EXE 传入 `--desktop`：

```powershell
$taskExe = (Get-Content D:\fences\dist\latest.txt).Trim()
& $taskExe --desktop
```

先显示管理面板。点击“窗口预览”查看分组；点击“启动桌面模式”将本软件的分组窗口挂接到桌面承载窗口。可以拖动分组标题栏、拖动右下角改变尺寸、点击右上角 ⌃ 折叠，双击标题或边框打开对应的系统文件夹，或把文件拖入分组。双击项目可打开，右键可查看文件位置、复制路径或改变分组。

关闭面板会收至系统托盘；通过“退出栖桌”彻底退出。Ctrl+Alt+D 显示/隐藏本软件分组，Ctrl+Alt+左右方向键切换页面。若热键冲突，面板会显示提示。

### 桌面没有显示时

通过旧版面板的“退出栖桌”退出旧进程，再运行 `code/start.ps1` 启动最新版本，点击“启动桌面模式”。关闭面板右上角的叉号只会收至托盘，不会退出旧版。

本次修复严格识别 Explorer 的 Progman / WorkerW 桌面窗口，避免误选文件夹映射视图；透明分组保持顶层窗口的屏幕坐标，通过桌面窗口所有权连接桌面。屏幕外分组会在启动显示时自动恢复到可触及的位置，正常的副屏负坐标会保留。也修复了导入对话框的初始路径问题。

为确认实际效果，建议暂时停用 Fences 的桌面整理功能，关闭 Fences 设置窗口并不一定会停用它。无需卸载 Fences；本机窗口挂接检查在 Fences 仍运行时已经通过。具体视觉重叠和前后台行为还需要实测。

## 当前功能

- 桌面分组、窗口预览、标题拖动、尺寸调整、折叠、位置锁定、颜色和透明度。
- 文件/快捷方式拖入分组，改变归属，打开和定位文件。
- 文件夹映射：直接枚举文件夹内容，定时刷新，按名称、类型或修改时间排序。
- 名称搜索、分页、全局隐藏、隐藏排除项。
- 扩展名和名称包含规则，按顺序首次匹配，自动归类新桌面文件。
- JSON 配置持久化、布局快照、恢复、撤销。
- 从 `research\evidence\fences-config.json` 导入 Fences 分组、图标归属和页面；规则暂不导入。导入后自动归类关闭，可撤销导入。
- 基于规则的分类建议；Ollama / 兼容 Chat Completions 服务的 AI 请求、建议预览和勾选应用。

分组操作只改变本软件配置中的归属，文件仍在原路径。文件夹映射窗口显示真实目录内容，当前拖入该窗口不会触发文件移动。移除分组或项目不会删除磁盘文件。

## 已知差距

当前使用本软件自己的图标视图。快速隐藏页面提供原桌面图标整层隐藏开关，默认关闭；尚未逐个接管 Explorer 图标。开启后也会隐藏回收站等系统图标，停止、预览或退出会恢复原状态，独立进程支持拥有者异常退出后的恢复。多个桌面整理程序同时启用手势时可能相互影响。

桌面空白双击、组内文件夹导航和布局工作区档案已实现。实际桌面手势、真实显示器切换和不同 DPI 仍需实测；全部 Fences 规则条件、第三方 Shell 菜单扩展与实际 Explorer 重启恢复尚未完整验证。桌面承载窗口变化检测已有代码，尚未通过真实 Explorer 重启测试。

模型请求代码已接入 UI；没有实际连接你的模型服务验证。Ollama 默认地址为 `http://127.0.0.1:11434`，可在设置中更改。兼容服务使用 `/v1` 根地址；API 密钥从 `QIDESK_AI_KEY` 环境变量读取。仅发送文件名、扩展名、是否为文件夹与分组名称。

## 配置与验证

本机配置保存在 `%LOCALAPPDATA%\QiDesk\state.json`，快照在同目录 `snapshots`。写入使用临时文件替换并保留备份，格式错误的原配置会保留副本。

```powershell
& D:\fences\code\build.ps1
$taskExe = (Get-Content D:\fences\dist\latest.txt).Trim()
$taskTests = (Get-Content D:\fences\dist\latest-tests.txt).Trim()
& $taskTests --self-test --native-test
& $taskExe --render-settings
```

构建现在产出三个产物：`QiDesk-*.exe`（正式程序）、`Mcp-QiDesk-*.exe`（MCP 服务）和 `Tests-QiDesk-*.exe`（测试，含 `--self-test`）。自检入口只存在于测试产物中，正式程序与 MCP 产物不再包含测试代码。

构建使用系统 .NET Framework 4.x 编译器，无需下载 SDK。每次构建生成带时间标识的独立 EXE，避免覆盖被占用的文件。118 项检查覆盖规则、唯一归属、撤销、快照、重新加载、移出分组的排除状态、文件夹枚举和配置导入，以及误选桌面窗口的防护、屏幕外恢复、真实透明分组的挂接、坐标保持和隐藏后显示。原生测试会短暂显示本软件的测试分组，随后关闭。`--render-settings` 只渲染本软件界面，生成十三个 `dist\settings-*.png` 及分组/映射预览。示例映射仅写入独立 render-state，不写入实际配置。

## 组件功能区、组合分享与首次教程

Alt＋Space 现在替代 Shift＋Z 唤起工作区搜索。桌面组件区、主页和托盘提供“＋ 添加组件”；桌面左键长按框选菜单也新增“在此添加组件”。

## 组件渲染类型扩展

插件清单仍为 JSON 描述，不执行外部代码；本轮把可用渲染类型从八种扩展到十二种，内置组件、自定义 `.qidesk-plugin.json` 插件与组合包都可选用：

- 计算器（calc）：桌面四则运算，支持括号与小数，实时预览结果；不执行脚本，表达式由本地解析器求值。
- 习惯打卡（habit）：每天点一次记录打卡，显示连续天数与累计天数；打卡记录保存在本机组件数据中，不随组合分享导出。
- 系统状态（system）：读取 CPU 占用、内存占用与所选磁盘可用空间及开机时长；在设置中可指定盘符，留空使用系统盘。
- 照片轮播（photos）：循环播放指定文件夹内的图片，支持左右切换，每 8 秒自动换一张；在设置中点“选择文件夹”指定目录。

自定义插件、组合导出与安装预览沿用原有流程；新类型同样参与组件库预览、尺寸下限校验和页面自动排列。示例见 code/plugins/examples/daily-water.qidesk-plugin.json 与 utility-desk.qidesk-pack.json。预览见 dist/component-qidesk.calc-preview.png 等。

## 日历与时钟（农历）

日历组件对齐当代中文日历：每格显示公历日与农历小字，初一显示月份，节气由本地公式计算，公历节日与春节、元宵、端午、七夕、中秋、重阳、腊八、除夕优先显示；周末用强调色，今天整格高亮。可在设置中开启“在日历中显示时钟”，在标题下显示当前时间与“农历九月初七”；时钟组件也在日期行追加农历日。设置含“显示农历、节气与节日”“在日历中显示时钟”“一周从周一开始”，默认周一开始。农历数据覆盖 1900–2100，超出范围回退公历；日历缩小时内容可滚动。实现与验证见 research/COMPONENT-LIBRARY.md，预览为 dist/component-calendar-preview.png 与 dist/component-clock-preview.png。

## 网易云音乐组件

新增 `music` 渲染类型（内置组件“网易云音乐”，id 为 qidesk.music，强调色 #C20C0C）。它读取网易云音乐客户端主窗口标题（播放时形如“歌名 - 歌手”）作为正在播放信息：显示歌名、歌手；按钮“上一首 / 播放 / 暂停 / 下一首”通过系统媒体键控制当前播放器；未检测到客户端或未播放时显示相应提示。网易云没有公开的本地播放接口，因此不显示专辑封面与进度，也不读取账号信息。若客户端装在别处或想指向其它播放器，可设置环境变量 `QIDESK_MUSIC_PROCESS` 指向对应进程名。实现与验证见 research/COMPONENT-LIBRARY.md，预览为 dist/component-qidesk.music-preview.png。

## 桌面面板与多文件夹标签

分区面板支持顶部文件夹标签：把文件夹拖到面板顶部栏位（或用 ＋ 选择）即可新增标签，点标签切换、点 × 关闭；双击文件夹进入子文件夹，文件区第一格是“↑ 上一层”，再次点击当前标签回到根目录。每个标签各自记录浏览位置。

“生成默认面板”（主页按钮；首次运行自动创建一次）在右下角竖排最多三个面板，宽度约 6 个图标，高度按工作区高度三等分：文件夹（多文件夹标签面板）、工作内容（桌面上的文档、图片与影音）、应用（桌面上的程序与快捷方式）。

排列默认只移动位置、不拉伸分区；可选“排列时按内容缩小分区（只缩不放）”按文件数量收缩多余空白，空分区收到最小尺寸。实现与验证见 research/DESKTOP-PANELS.md。

## 工作区面板与桌面小猫

参考 `references/PathCat-main`（径猫）的文件侧栏。Alt＋Space 会把**已选中的多个桌面分区一起置顶**，再次按下收起；没有选中分区时，打开或收起原来的置顶工作区文件面板。文件面板可拖动标题或空白处移动，位置尺寸自动保存。顶栏的文件夹标签绑定真实目录，分区标签引用桌面分区；点标签切换，点 × 或中键关闭，点 ＋ 或把文件夹拖到栏位新增。

`Ctrl＋滚轮`（或 `Ctrl＋＋/－`）在一条缩放线上移动：**大图标 → 中 → 小 → 详细信息 → 列表 → 可折叠树**。最紧凑的树可以点 ▸ 展开子目录，只加载展开过的目录。

面板里直接操作真实文件，按 VSCode / Cursor 侧栏的习惯：**直接拖动是移动，按住 Ctrl 拖动是复制**；`Ctrl＋C/X/V` 复制剪切粘贴，`F2` 重命名，`Delete` 二次确认后移入回收站，文件可以直接拖到 Cursor、浏览器或聊天窗口里。移动和重命名会同步更新分区归属、忽略路径和面板标签本身。

`Ctrl＋F` 展开名称搜索：只在当前文件夹及子目录里按名称匹配，显示相对路径，最多 2000 项，遵循忽略规则与 `.gitignore` / `.cursorignore`；不做内容检索，不引入向量或语义模型。面板和桌面分区右上角的**忽略图标**是拖放目标：把文件或文件夹拖上去只在当前标签或分区忽略。管理界面的“忽略文件”页同时显示全局和当前分区规则；导入的规则可逐条修改，修改保存在栖桌的独立副本中。

**外观完全复用桌面分区那一套**：颜色、色调强度、背景与边框不透明度、标签颜色字号、图标皮肤，默认**方角**。新增底色可选**跟随颜色 / 纯色 / 渐变 / 毛玻璃 / 图片**，支持自定义背景图与填充方式，也可以让面板「跟随某个分区」的外观，桌面分区同样受益。

**钉到桌面 / 弹成面板**：面板标题上的图钉把面板变回一个真实分区；分区标题右键「弹成工作区面板」把它接进面板当标签，桌面那份先隐藏、收起后回到桌面。在桌面分区标题上 **Ctrl＋左键**或点右上角圆点可选择多个分区，Alt＋Space 或 Enter 把它们作为独立面板一起置顶。再按一次收起；`Ctrl＋Alt＋Backspace` 清除所有选择并恢复桌面显示。悬停标题时，右上角还会出现“从工作区选择中移除”、拖放忽略入口和“× 删除分区”；删除分区可撤销，不删除磁盘文件。

桌面小猫现在默认使用 PathCat 自带的状态图，可选**默认猫 / 毛绒三花 / 矢量猫**（素材缺失时自动回退到内置矢量画法，素材来源见 code/assets/cat/SOURCE.md）。点击开合工作区面板，鼠标停留约 0.5 秒自动展开且不抢焦点，拖文件夹到猫身上新建文件夹标签，可拖动改位置、可调整 75 %–200 % 大小，5 分钟不互动进入睡眠。**隐藏小猫有四个入口**：小猫右键菜单、托盘、`Ctrl＋Alt＋M`、面板标题上的「猫」按钮。

原来的工作区搜索浮条改到小猫右键菜单与托盘里。实现与验证见 research/WORKSPACE-PANEL.md，预览为 dist/workspace-panel-preview.png、dist/workspace-panel-tree-preview.png、dist/workspace-panel-acrylic-preview.png、dist/desktop-pet-preview.png 与 dist/desktop-pet-calico-preview.png。
