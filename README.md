# 栖桌 · AI Desktop

一款面向 Windows 的桌面整理工具，让文件、文件夹和常用工具以分区的形式留在桌面上。

基于 C#、WPF 与 .NET Framework 4.x 开发，当前为 **0.7.1 核心预览版**，功能和交互仍在完善。

## 功能

### 桌面分区

- 将桌面文件和快捷方式整理到不同分区，支持拖入、拖出与分区内操作。
- 调整位置、大小、颜色、透明度与图标外观，支持折叠和多页面布局。
- 把文件夹映射到桌面，在分区中浏览目录。
- 将多个分区合并为标签，按需要切换或拆出。

### 工作区与搜索

- 选中常用分区组成工作区，通过小猫或 `Alt+Space` 唤起，再次操作放回桌面。
- 在分区内使用 `Ctrl+F` 搜索文件，不另开工作区窗口。
- 使用 `Ctrl+Alt+Space` 呼出快捷搜索栏，也可将搜索添加为桌面组件。
- 可选连接 Everything 搜索全盘文件；未连接时使用范围有限的本机搜索。

### 整理与个性化

- 按文件类型和名称规则整理桌面，支持全局与分区独立的忽略规则。
- 保存布局快照，支持恢复和撤销布局操作。
- 提供应用图标皮肤与自定义显示图标，保留素材来源和许可说明。
- 添加时钟、待办、番茄钟等桌面组件。
- 动态矢量三花桌宠，支持眨眼、呼吸、摆尾和工作区交互。
- 可选连接 AI 服务生成整理建议。
- 桌面管理能力通过 MCP 与命令行完整开放给 AI：读取布局、整理分区、把 SVG 生成图标并替换快捷方式图标、安装组件插件；布局操作可撤销，AI 改过什么有回执可查，工具清单与安全边界见 [AI 整理 Skill](code/skills/qidesk-organizer.md)。

## 使用方式

打开应用后，在控制面板中创建分区或添加文件夹映射，再启动桌面模式。文件可以拖入分区，分区的标题栏用于移动、切换标签与相关操作。

关闭控制面板会收至系统托盘。需要恢复原生桌面时，使用“停止桌面 · 恢复 Windows 图标”；需要退出应用时，使用“完全停止栖桌”。

整理后的桌面项目会记录恢复信息。停止桌面模式或正常退出时，应用尝试恢复原桌面项目；异常退出后，下次启动会检测并处理残留记录。删除分区与删除磁盘文件是不同操作。

## 当前状态

本项目仍处于开发阶段，尚未发布稳定版。多显示器、不同 DPI、Explorer 重启及与其他桌面整理软件同时运行的行为，仍需持续验证。

`code/` 包含应用源码、资源、测试、构建脚本及 Everything 搜索依赖，构建时自动附带搜索程序和接口文件。首次使用全盘搜索仍需启动 Everything 并完成索引设置；AI 等外部服务需自行配置。构建产物、本机配置、用户桌面文件和研究资料不随源码提交。
