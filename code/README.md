# 栖桌

Windows x64 桌面分区应用，使用 C# / WPF。运行 `build.ps1` 后，`../dist/latest.txt` 指向最新主程序。

## 使用

打开主程序，在主页点击“启动桌面模式”。Windows 原生桌面图标、空白处右键和拖放继续由 Explorer 处理。未放入分区的散落图标默认不自动归类；需要时可在 Windows 桌面空白处右键，选择“栖桌：整理散落图标”或“栖桌：排列分区与组件”。

把桌面文件拖到分区可加入分区；把分区中的桌面文件拖回桌面空白处可移出分区，也可在该文件的右键菜单选择“移出此分组”。左键拖动分区标题时按住右键并向左或向右拖过 80 像素，可将分区移到栖桌相邻页面。

每个分区顶栏是一条 Chrome 式标签栏：分区自身、文件夹映射和合并分区都是同一种标签，只是内容来源不同。点击标签切换，悬停后点 × 关闭，拖到另一个分区的标签栏即可合并，拖到桌面空白处则恢复/拆成独立分区；文件夹标签拖出后会变成独立文件夹分区，目录和该目录的忽略规则一起带走，磁盘文件不动。双击分区标签改名，＋ 可添加文件夹标签或新建空分区标签。

在桌面分区标题上 **Ctrl＋左键**或点击右上角圆点选择工作区。点击小猫或按 `Alt＋Space` 将选中的分区唤到当前软件前方，再次操作将其放回桌面层且保持可见；点击其他应用时分区按普通窗口层级切换。中键点击已选分区可收起或唤起。无选择时提示先选择，不另开面板。`Ctrl＋Alt＋Backspace` 取消全部选择并放回桌面。最右侧 × 收起当前整个分区；控制面板卡片右键“在桌面显示分区”可恢复，删除分区在右键菜单。

当前分区获得焦点后，`Ctrl＋F` 打开名称搜索，再按一次关闭。文件夹分区搜索当前目录及子目录；普通分区搜索已有成员，均遵循相同的忽略规则。搜索结果仍在原分区中操作。全盘搜索保留在小猫右键和托盘入口，可使用 Everything。

全局忽略规则可在单独分区中取消继承、独立修改或恢复继承，其他分区不受影响。组合分区的所有标签共用规则；导入 `.gitignore` 后修改独立副本，不改源文件。顶部空白或 ⠿ 手柄可拖动折叠栏，保留折叠状态及展开尺寸。

主页“停止桌面 · 恢复 Windows 图标”只关闭栖桌桌面窗口，管理面板仍可使用。“完全停止栖桌”会退出应用并移除栖桌的桌面右键入口。若栖桌异常退出（崩溃或被强制结束），下次启动会检测残留的隐藏记录并自动恢复 Windows 桌面图标。

已整理的桌面项目使用可恢复的隐藏属性；受保护项目不能设置属性时，保存恢复映射后移入受管目录。停止桌面模式或退出时恢复原桌面项目，失败记录保留供下次重试。文件夹映射与真实文件移动分别处理。

`state.json` 损坏时不会直接重置：先逐项修复（重复分组 ID、越界字段、损坏的插件/组合/忽略记录），原文件备份为 `state.json.corrupt-时间`；确实修不好时至少保留隐藏与受管项目的恢复映射，避免 Windows 桌面图标停留在隐藏状态。

手动快照与每次应用布局生成的快照保留最近 30 份，`auto-*.json` 自动快照按设置保留天数清理。

桌面项目右键“更换显示图标…”可为任意文件、文件夹或快捷方式指定图标来源（`.ico`、`.exe`、`.dll`、`.icl` 或图片），只改栖桌内的显示，不写真实文件；重命名或移动后跟随，来源失效时回退系统图标，可在设置页一次性全部恢复。快捷方式另有“更换快捷方式图标…”，那一项改的是 `.lnk` 本身，资源管理器里也会变。

## 开发

`src/` 是应用源代码，`src/tests/` 是单独编译的测试代码。`build.ps1` 生成主程序、MCP 程序和测试程序到 `../dist/`。最新测试程序见 `../dist/latest-tests.txt`。

主程序同时是命令行入口：`QiDesk.exe --call <任意 MCP 工具> --json '{...}'` 或 `--arg 键=值`，与 MCP 走同一套校验和实现，结果以 JSON 输出；`--build-icon <svg> <ico>` 不需要运行栖桌即可生成多尺寸图标。完整的工具面、标准流程和安全边界见 [skills/qidesk-organizer.md](skills/qidesk-organizer.md)。

`assets/` 保存应用资源，`vendor/everything/` 保存全盘搜索需要的官方程序、DLL、ES、语言包与许可。构建时自动复制到输出目录，不依赖仓库外的 `tools/` 或参考项目。首次使用在“文件搜索”页启动并检查索引连接，依赖来源和使用说明见 [Everything 搜索依赖](vendor/everything/README.md)。

对操作系统的一切读取都收拢在 [src/SystemAccess.cs](src/SystemAccess.cs)：桌面、公共桌面、图片、文档、最近使用、Program Files、数据目录以及 `QIDESK_*` 环境变量，只在这里访问，其他文件不直接调用 `Environment`。需要把位置换到别处（跑测试、便携运行）时，在 exe 旁放一个 `system.json` 即可，例如 `{"folders":{"Desktop":"D:\\Desk"},"variables":{"QIDESK_AI_KEY":"sk-..."}}`；没写的键继续跟随操作系统，文件损坏时按没有覆盖处理，不会挡住启动。自检见 [src/tests/SystemAccessTests.cs](src/tests/SystemAccessTests.cs)。
