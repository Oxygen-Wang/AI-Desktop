# 栖桌

Windows x64 桌面分区应用，使用 C# / WPF。运行 `build.ps1` 后，`../dist/latest.txt` 指向最新主程序。

## 使用

打开主程序，在主页点击“启动桌面模式”。Windows 原生桌面图标、空白处右键和拖放继续由 Explorer 处理。未放入分区的散落图标默认不自动归类；需要时可在 Windows 桌面空白处右键，选择“栖桌：整理散落图标”或“栖桌：排列分区与组件”。

把桌面文件拖到分区可加入分区；把分区中的桌面文件拖回桌面空白处可移出分区，也可在该文件的右键菜单选择“移出此分组”。左键拖动分区标题时按住右键并向左或向右拖过 80 像素，可将分区移到栖桌相邻页面。

按 `Alt+Space` 打开文件面板：顶部是分区标签栏（全部 / 各桌面分区 / 忽略 / 最近），下方是与桌面一致的文件网格；`Ctrl+F` 或直接输入即搜索，`Esc` 收起。把文件夹拖到顶部空白处会新建文件夹分区，把文件拖到某个分区标签会加入该分区；右键标签或空白处可快捷新建分区、添加文件夹映射或刷新。搜索优先使用 Everything（`tools/everything-es/es.exe`，可在设置中选择 Everything 程序），未连接时回退到桌面与已连接项目的本机扫描。

主页“停止桌面 · 恢复 Windows 图标”只关闭栖桌桌面窗口，管理面板仍可使用。“完全停止栖桌”会退出应用并移除栖桌的桌面右键入口。若栖桌异常退出（崩溃或被强制结束），下次启动会检测残留的隐藏记录并自动恢复 Windows 桌面图标。

主页“停止桌面 · 恢复 Windows 图标”只关闭栖桌桌面窗口，管理面板仍可使用。“完全停止栖桌”会退出应用并移除栖桌的桌面右键入口。

现阶段分区只记录桌面文件的逻辑归属，不移动实体文件。由于 Explorer 图标层保持运行，同一文件可能同时出现在原生桌面和栖桌分区里。

## 开发

`src/` 是应用源代码，`src/tests/` 是单独编译的测试代码。`build.ps1` 生成主程序、MCP 程序和测试程序到 `../dist/`。最新测试程序见 `../dist/latest-tests.txt`。
